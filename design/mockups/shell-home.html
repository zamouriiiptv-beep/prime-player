State language

Six readings a user must never confuse, said in one grammar. Colour carries a fixed meaning everywhere — violet is navigation, aqua is now, amber is working, neutral is the past — and no state is ever colour alone.

Item history · the bar under the artwork

Not started
No mark. Absence is the cheapest signal there is.
In progress
Partial, in brand violet. The width is the resume point, not decoration.
Watched
Recently watched
Full width, neutral, artwork dimmed a third. History is not a status, so it takes no colour — which is exactly what keeps it clear of "playing".
PLAYING
Playing now
Aqua bar, aqua inner edge, and the only moving mark in the interface. One item at a time, so it can afford to be the loudest thing on screen.

Surface state · where you are, and what is working

Live TV
Focused
Lift 4%, violet ring, glow. Transient — it follows the cursor and nothing else.
Home
Selected
Violet indicator on the leading edge and a violet label. Persistent — it is where you are, whether or not the cursor is there.
Movies refreshing
Loading
Amber hairline and a word. The destination stays focusable while it fills — a keypress is never dropped because data has not arrived.
Live TV Playing
Playing (destination)
The section a stream is running in carries the aqua meter at its trailing edge, so "where I am" and "what is on" are never the same mark.

Motion · three levels, chosen by the device, overridden by the user

Full
  • Aurora backdrop animates
  • Focus lifts and cross-fades
  • Playing meter animates
  • Counts tick when they change
Reduced
  • Backdrop is a static gradient
  • Focus is instant — ring and colour, no scale
  • Playing meter is static bars
  • Counts swap without ticking
Disabled
  • Nothing moves anywhere
  • Every transition is a state swap
  • All six states above still read
  • Full function, zero animation

Chosen automatically from device capability and the platform's reduce-motion setting, then overridable in Settings → Appearance. The automatic choice is a starting point, never a ceiling.

Counts · quiet, cached, and only animated when they actually change

Live TV · 12,480 +128 new Opening a screen reads the cached count and renders it — no animation, no flicker, no query. Only a refresh that genuinely changes the number ticks it up and shows the delta, which fades after four seconds. A count that animates every time you arrive is noise pretending to be life.
