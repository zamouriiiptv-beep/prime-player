# Castivio TV

مشغل IPTV لنظام أندرويد (Kotlin + Jetpack Compose)، مصمم للهواتف وأجهزة Android TV.

## الحالة الحالية

المرحلة الأولى: **شاشة التفعيل الأولى** التي تظهر عند فتح التطبيق لأول مرة.

تتضمن:
- عرض **معرّف الجهاز بصيغة MAC** ثابت لكل جهاز (يُولّد محليًا لأن أندرويد يمنع قراءة الماك الحقيقي).
- عرض **مفتاح الجهاز** (رقم مكوّن من 6 خانات).
- زر نسخ لكل من المعرّف والمفتاح.
- **رمز QR** يحتوي على رابط تفعيل الجهاز على بوابة castivio.
- خيار الإضافة اليدوية عبر **Xtream Codes** (سيرفر + مستخدم + كلمة مرور).
- خيار الإضافة اليدوية عبر **رابط M3U / M3U8**.

يُحفظ مصدر القائمة في `SharedPreferences`.

## طرق تحميل قائمة التشغيل (الرؤية الكاملة)

1. **عبر عنوان الماك** (الأهم) — يتطلب بوابة تفعيل على الويب تربط الماك بالقائمة *(مرحلة قادمة)*.
2. **Xtream Codes** — مُنفّذ في واجهة الإدخال.
3. **رابط M3U** — مُنفّذ في واجهة الإدخال.

## متطلبات البناء

- JDK 17
- Android SDK (compileSdk 34)
- الوصول إلى **Google Maven** (`dl.google.com` / `maven.google.com`) لتنزيل Android Gradle Plugin و Jetpack Compose.

```bash
./gradlew assembleDebug
```

> ملاحظة: لا يمكن بناء المشروع في بيئة تحجب Google Maven. استخدم جهازك المحلي أو بيئة CI تسمح بالوصول إلى `dl.google.com`.

## بنية المشروع

```
app/src/main/java/com/castivio/tv/
├── MainActivity.kt              # التنقل بين الشاشات
├── data/
│   ├── DeviceIdentity.kt        # توليد وحفظ معرّف الماك والمفتاح
│   └── SourceStore.kt           # حفظ/تحميل مصدر القائمة (Xtream / M3U)
├── ui/
│   ├── Theme.kt                 # ألوان وخلفية متدرجة
│   ├── WelcomeScreen.kt         # شاشة التفعيل الأولى
│   └── AddSourceScreens.kt      # نماذج Xtream و M3U
└── util/
    └── Qr.kt                    # توليد رمز QR
```

## الخطوات القادمة

- جلب القنوات من المصدر المحفوظ وعرضها في قائمة.
- مشغّل الفيديو (Media3 / ExoPlayer).
- بوابة التفعيل عبر الماك على الويب.
